# ☕ Cafè L’Antic & Nou

Sitio web desarrollado para un café clásico con esencia artesanal y diseño moderno.  
Una experiencia visual cálida y minimalista que fusiona lo tradicional con lo contemporáneo.

---

## 🛠️ Tecnologías utilizadas

- **React**
- **Vite**
- **Tailwind CSS**
- **JavaScript**

---

## ✨ Características

- Secciones informativas: menú, galería, ubicación y contacto.
- Diseño limpio y adaptable a cualquier dispositivo.
- Tipografía cálida y tonos suaves que refuerzan la identidad del café.
- Enfoque en la experiencia del usuario y la navegación intuitiva.
